# GameMates

GameMates is a desktop app for gamers who want to keep track of the friends they play with across different games.

It helps users store each friend's contact details, the games they play, their in-game usernames, and game-specific notes such as roles, servers, preferred weapons, or play styles. 
GameMates is optimized for users who prefer a fast command-line workflow while still having a visual desktop interface.

## Features
* Add, edit, delete, list, and filter friends.
* Store optional contact details such as phone numbers and email addresses.
* Add games to each friend with their in-game username.
* Record extra game-specific information.
* List or filter friends by name or game.
* View, filter, and delete game entries for each friend.
