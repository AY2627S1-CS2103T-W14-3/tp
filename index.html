GameMates

Keep your gaming friends in one place

GameMates is a desktop app for gamers who want to remember who they play with and the usernames their friends use across games. Manage friends with typed commands and check their details in a visual panel alongside the friend list. Your friends and game entries are saved locally for your next session.

What you can do

  • Add friends with just a name, optional phone/email details and tags; edit or delete them later.
  • Find friends by name or list friends who play a particular game.
  • View a friend’s or your own games and in-game usernames, or show only one matching game with gamelist.
  • Add or remove games for a friend or your own profile using gameadd and gamedel.
  • Edit your own profile using edit myself, keep it separate from friends, and back up your local data file.

For example, list g/Valorant lists Valorant players. Then gamelist 1 g/Valorant shows the first displayed player’s Valorant card without changing the filtered friend list.

Add roles, levels and other game details with gameadd 1 g/Valorant u/player m/Role:Support m/Level:20. Metadata appears below the username in each game card. See the User Guide.

Get started

  • Download GameMates and follow the Quick start. Java 25 or later is required.
  • Use the User Guide for command formats, examples, validation and backup steps.
  • Read the Developer Guide for the design, implementation and manual test instructions.
